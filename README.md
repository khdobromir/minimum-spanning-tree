# Курсовая работа: построение минимального остовного дерева

Проект предназначен для построения минимального остовного дерева взвешенного графа. Предусмотрены чтение данных о рёбрах из файла, построение остова алгоритмами Прима и Крускала и поиск пути между двумя выбранными вершинами полученного дерева.

## Планируемые возможности

- Чтение информации о рёбрах графа из файла.
- Хранение вершин и рёбер в структурах данных, подходящих для используемых алгоритмов.
- Перебор рёбер и выбор ребра с наименьшим весом, которое можно добавить в строящееся дерево.
- Построение минимального остовного дерева алгоритмом Прима.
- Построение минимального остовного дерева алгоритмом Крускала.
- Поиск пути между двумя произвольными вершинами построенного дерева.

## Устройство проекта

В основе реализации — классы для представления ребра, графа и минимального остовного дерева. Отдельные методы будут отвечать за чтение данных, выбор подходящих рёбер, построение дерева и поиск пути. Взаимодействие классов проектируется по принципам объектно-ориентированного программирования с применением наследования, шаблонов и перегрузки методов там, где это уместно.

Выбор структур данных для рёбер и вершин должен учитывать эффективность обоих алгоритмов и сопровождаться обоснованием.

## Демонстрация

Демонстрация на входном графе покажет построение минимального остовного дерева каждым из двух алгоритмов и путь между двумя выбранными вершинами полученного дерева. Также будет объяснён выбор структур данных для хранения рёбер и вершин.
